# esp32-iot-monitoring
IoT environmental monitoring using ESP32 and Wokwi simulation

Temperature & humidity monitoring using DHT22 sensor and 16x2 LCD display.

## Hardware
- ESP32
- DHT22 sensor
- 16x2 I2C LCD display

## Features
✅ Real-time temperature monitoring
✅ Real-time humidity monitoring
✅ LCD display output
✅ Error handling
